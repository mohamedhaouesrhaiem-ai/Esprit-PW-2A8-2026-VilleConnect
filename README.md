# VilleConnect - Modules Événements & Signalements

## Overview
This project was developed as part of the Projet Web - 2nd Year Engineering Program at **Esprit School of Engineering** (Academic Year 2026-2027).
VilleConnect is an intelligent platform for urban services. This repository contains the **Events & Participation Module** (Mohamed) and the **Urban Reports Module** (Adem).

## Features
- **Events**: View city events, register online (Front Office), manage events (Back Office).
- **Reports**: Submit urban issues (Front Office), track and update their status (Back Office).
- MVC Architecture using PHP Object-Oriented Programming.

## Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap 5 (eLEARNING Template)
- **Backend**: PHP (POO), PDO, MySQL
- **Architecture**: MVC

## Getting Started
1. Clone the repository into `htdocs`.
2. Import `database.sql` (for Events) into phpMyAdmin.
3. Import `database_adem.sql` (for Reports) into phpMyAdmin.
4. Open `http://localhost/VilleConnect/Views/front/events.php` (Events) or `http://localhost/VilleConnect/Views/front/signalements.php` (Reports).
5. Back Office: `http://localhost/VilleConnect/Views/back/admin_events.php` and `admin_signalements.php`.
