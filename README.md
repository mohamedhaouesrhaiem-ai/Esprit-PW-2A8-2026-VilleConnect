# VilleConnect - Module Événements & Participation

## Overview
This project was developed as part of the Projet Web – 2nd Year Engineering Program at **Esprit School of Engineering** (Academic Year 2026–2027).
VilleConnect is an intelligent platform for urban services. This repository contains the **Events & Participation Module**, allowing citizens to view city events and register online, while administrators manage them via a Back Office.

## Features
- View list of upcoming events (Front Office).
- Register for events.
- Dashboard to manage events (Back Office).
- MVC Architecture using PHP Object-Oriented Programming.
- Template integration using `require_once` (includes).

## Tech Stack
### Frontend
- HTML5, CSS3, JavaScript, Bootstrap 5 (eLEARNING Template)

### Backend
- PHP (POO), PDO
- MySQL Database

### Architecture
- MVC (Model-View-Controller)

## Getting Started
1. Clone the repository.
2. Place the folder in `htdocs` (XAMPP).
3. Import the SQL file into phpMyAdmin to create the `villeconnect` database.
4. Update database credentials in `config.php` if needed.
5. Open `http://localhost/VilleConnect/Views/front/events.php`.
